# Cycling Agentic Flow

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (NKimball1/cycling-agentic-flow), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage roles, each label named after its role (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the repo root and ADRs in `docs/decisions/`. See `docs/agents/domain.md`.
